English

Current version: advertising and tracking

Advertising is disabled in version 1.01. The game does not initialize Yandex Mobile Ads, request or display ads, or collect advertising impressions and clicks. It does not link data from the game with data from other companies for targeted advertising or advertising measurement, and does not share data with data brokers. This version does not request App Tracking Transparency permission because it does not perform this kind of tracking.

Gameplay analytics

Player release builds use Google Analytics for Firebase to measure active sessions, playtime, retention and gameplay events. Analytics data can include a random installation identifier assigned by the game, the Firebase app instance identifier, event times, gameplay progress and interactions, language, app version, device and operating-system information, and approximate location that Firebase derives from a masked IP address. These data are associated with an installation for analytics. We do not send your name, email, phone number or Game Center account to Firebase.

Advertising features of analytics

The integration uses Firebase Analytics Core without IDFA collection. IDFV collection, advertising storage, advertising user data use and ad personalization are disabled. Analytics data is not used by this app for targeted advertising. Development and automated test traffic is excluded from remote gameplay analytics. Firebase privacy information: https://firebase.google.com/support/privacy

Local progress and diagnostics

Game progress, currencies, upgrades, cat cards, settings and preferences are saved on your device. Local diagnostic logs and MetricKit crash and performance payloads remain on the device; this app does not upload these logs through a crash-reporting SDK. Firebase may process technical app and device information needed to operate its analytics service.

Game Center

If you use Game Center, achievements, leaderboard scores and the identifiers needed for those features are handled by Apple under its privacy policy: https://www.apple.com/legal/privacy/ . Game Center participation is optional. No game account or login is required to play.

Earlier versions

Earlier versions may offer optional rewarded ads supplied through Yandex Mobile Ads. Advertising data processing in those versions is described by Yandex: https://yandex.ru/legal/confidential/ . Advertising is disabled in version 1.01.

Data sale

The game does not sell personal data.

Children

The game is intended for a general audience. If you believe a child has supplied personal information through the app, contact the developer.

Changes and contact

This policy may be updated when app functionality or data handling changes. Questions and data requests can be sent to viktordee41@icloud.com.

Русский

Текущая версия: реклама и отслеживание

В версии 1.01 реклама отключена. Игра не инициализирует Yandex Mobile Ads, не запрашивает и не показывает рекламу, не собирает данные рекламных показов и кликов. Данные игры не объединяются с данными других компаний для таргетированной рекламы или измерения её эффективности и не передаются брокерам данных. Эта версия не запрашивает разрешение App Tracking Transparency, поскольку такого отслеживания нет.

Игровая аналитика

Пользовательские Release-сборки используют Google Analytics for Firebase для оценки активных сессий, времени игры, удержания и игровых событий. Аналитика может включать случайный идентификатор установки, созданный игрой, идентификатор экземпляра приложения Firebase, время событий, игровой прогресс и действия, язык, версию приложения, информацию об устройстве и операционной системе, а также приблизительное местоположение, которое Firebase определяет по маскированному IP-адресу. Для аналитики данные связаны с установкой. Имя, почта, телефон и аккаунт Game Center в Firebase не передаются.

Рекламные возможности аналитики

Интеграция использует Firebase Analytics Core без сбора IDFA. Сбор IDFV, рекламное хранение, использование пользовательских данных для рекламы и рекламная персонализация отключены. Игра не использует данные аналитики для таргетированной рекламы. Запуски разработки и автотесты исключены из удалённой игровой аналитики. Информация Firebase: https://firebase.google.com/support/privacy

Локальный прогресс и диагностика

Игровой прогресс, валюты, улучшения, карточки котиков, настройки и предпочтения сохраняются на устройстве. Локальные диагностические логи и данные MetricKit о сбоях и производительности остаются на устройстве; игра не отправляет эти логи через SDK отчётов о сбоях. Firebase может обрабатывать техническую информацию о приложении и устройстве, необходимую для работы аналитики.

Game Center

Если вы используете Game Center, достижения, результаты таблиц лидеров и необходимые для этих функций идентификаторы обрабатывает Apple по своей политике конфиденциальности: https://www.apple.com/legal/privacy/ . Использование Game Center необязательно. Для игры не требуются аккаунт и вход.
